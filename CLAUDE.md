# McReviewy-site

Public GitHub Pages site for the McReviewy extension (repo `s1son/McReviewy-site`): `index.html` and `privacy.html`, which is the privacy-policy URL in the extension's store listing. The extension itself is `../DrawingReview`.

- Plain HTML, no build. A push to `main` publishes it.
- `index.html` and `privacy.html` are currently identical copies; change both together.
- The privacy text must match what the extension actually does; when DrawingReview's `docs/privacy.md` changes, update this site in the same piece of work.
